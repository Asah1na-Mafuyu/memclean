# 验证记录

环境：本机 Windows build 26100，x64；Visual Studio 2022 Build Tools，MSVC 19.44；Release，静态运行库 `/MT`。日期：2026-10-24。

项目统一命名为 `memclean` 后，在独立目录重新完成构建、43 项核心检查和 20 项界面检查。构建入口为 `build.ps1 -UiTests`，分发产物为 `dist/memclean.exe`。

## 已执行

1. CMake / MSVC Release 构建通过。
2. `ctest --test-dir build -C Release --output-on-failure` 通过，内含 43 项检查：
   - Java、Minecraft、启动器、前台程序、同路径多进程及其子进程保护。
   - 系统、管理员、其他用户、关键进程、无桌面窗口和小工作集排除。
   - 前台身份未知或变化、目标 PID / 创建时间变化时跳过。
   - 取消与互斥锁释放；无符号内存差值边界。
   - 真实 `EmptyWorkingSet` 仅作用于本项目创建的 128 MB 隔离测试进程。
   - 实测工作集下降，随后逐页重读验证数据完整，测试进程正常退出。
   - 普通权限调用高级清理在入口被拒绝，没有触发全局 API。
3. `tests/ui_smoke.ps1` 通过 20 项界面检查：窗口创建、初始不执行、扫描、取消勾选、空选择按钮禁用、刷新、默认关闭的高级选项、互斥选择、界面绘制与正常退出。
4. 检查了普通与高级窗口的实际渲染图。
5. 导入表只含六个 Windows 系统 DLL；EXE 使用 ASLR、DEP、Control Flow Guard 和高熵地址随机化，无外部 C/C++ 运行库依赖。

测试没有清理用户正在运行的应用，也没有清理全局系统缓存。

## 尚未执行 / 适用边界

- 没有在这台工作机器上实际执行需要管理员权限的全局清理；也未自动接受 UAC。全局 API 的成功路径仍需在专用测试机或虚拟机实测。
- 没有跨多个 Windows 版本测试、长时间压力测试或游戏帧率测试。当前交付不宣称清理能提高游戏性能。
- Minecraft 保护是保守的进程名称、路径与进程树识别，未用真实游戏运行进行验收。
- 界面验证使用本机缩放；代码支持每显示器 DPI，但未做多显示器跨屏验收。

## 复现

在普通权限 PowerShell 中：

```powershell
.\build.ps1
.\tests\ui_smoke.ps1
```
